EMBERLINE is an original round-based tactical FPS built with three.js: mouse-look and WASD movement on the original Cinder Yard map, five weapons and two grenades, nine bots with waypoint routing, bomb plant and defuse rounds, an economy with a buy menu, and a full HUD. Single-player against bots, playable offline in a desktop browser — no build step, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
